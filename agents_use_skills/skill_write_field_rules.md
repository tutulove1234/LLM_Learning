一个skill，有限考虑一下三点：

1. 能力：清晰地描述这个技能是做什么的。
2. 触发条件：明确哪个用户请求应该激活它。
3. 边界：解释技能何时应该使用何时不应该使用。

并且，将最重要的触发关键词放在最开始，因为Codex可能缩短描述，当安装了许多技能的时候。

description 字段的语言约束：不必强求你自己使用英语，使用你能够精确表达workflow的你熟悉的语言种类。而不必强迫自己使用蹩脚的英语。

推荐使用熟悉的语言，如中文，加上一些技术上的标准英语词汇来相结合。提高你的工程技能。

name字段的语言约束：必须尊许命名规则即小写英语字母，数字和连字符。

body字段的语言约束：同description字段。
